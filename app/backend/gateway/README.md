# Gateway (Laravel 12)

The gateway is the only public entry point of the Salud Inteligente API.
It authenticates admins with Sanctum, proxies an explicit allowlist of routes to the internal FastAPI microservices, and aggregates the admin dashboard and health check.
See `openspec/changes/microservices-platform/design.md` (sections 1, 4 and 5) for the full contract this app implements.

## Error contract

Every error under `/api` is JSON with a Spanish message:

| Case | Status | Body |
| --- | --- | --- |
| Unknown route | 404 | `{"error": "Ruta no encontrada"}` |
| Missing/invalid token | 401 | `{"error": "No autenticado"}` |
| Authenticated but not admin | 403 | `{"error": "No autorizado"}` |
| Validation failure | 422 | `{"error": "<first message>", "errors": {...}}` |
| Rate limit exceeded | 429 | `{"error": "Demasiadas solicitudes, intenta en un momento."}` |
| Upstream unreachable | 503 | `{"error": "Servicio no disponible"}` |

Any other status code and body from an upstream service is passed through unchanged.

## Environment variables

| Variable | Purpose |
| --- | --- |
| `APP_KEY` | Laravel application key (generated by `composer create-project`) |
| `DB_CONNECTION`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` | Postgres connection (gateway's own `salud_gateway` database: users and personal access tokens only) |
| `SERVICE_BUSINESS_URL`, `SERVICE_CATALOG_URL`, `SERVICE_INVENTORY_URL`, `SERVICE_ORDERS_URL`, `SERVICE_ADVISOR_URL` | Base URLs of the internal microservices |
| `INTERNAL_TOKEN` | Shared secret sent as `X-Internal-Token` on every upstream call |
| `FRONTEND_ORIGINS` | Comma-separated list of allowed CORS origins for `api/*` |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | Seeded admin account, created only if it does not already exist |

## Running tests

```bash
composer install
php artisan test
```

Tests run against an in-memory SQLite database (see `phpunit.xml`) and fake every upstream call with `Http::fake()`, so no running microservices are required.

## Code style

```bash
./vendor/bin/pint
```

## Docker

```bash
docker build -t salud-gateway app/backend/gateway
```

The image waits for Postgres, runs migrations and seeders, then serves on port 8110 (see `docker-entrypoint.sh`).
